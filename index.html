日文字幕語法拆解小工具

從 Jimaku／kitsunekko 開字幕，每段一鍵複製，或丟給 Gemini 解說

1. 找字幕（Jimaku／kitsunekko）

直接在這裡搜尋 Jimaku、點檔案就會打開，手機平板也能用。 kitsunekko 的字幕大多也收在 Jimaku 裡（作品頁標「External」的那些）。 重新整理或下次回來時，會自動打開上次的字幕、停在上次按過的那一段（只記得最後一個檔）。

Jimaku API Key

到 jimaku.cc 免費註冊， 在 Account 頁 按產生 API key，貼到這裡。 只存在這台瀏覽器。

    電腦上直接從 kitsunekko 抓（書籤小工具）
    1. 第一次用：把這顆按鈕拖到瀏覽器的書籤列 → 📥 送到字幕工具
    2. 按 （一定要從這顆按鈕開，書籤才知道要把檔案送回哪個分頁）
    3. 在 kitsunekko 點進作品的資料夾，按書籤列上的「📥 送到字幕工具」，每個檔案旁會多一顆按鈕，按下去就會在這個分頁打開。

    為什麼要用書籤：kitsunekko 不讓其他網站直接讀取它的檔案，公開的代理伺服器也會被擋， 所以下載只能在 kitsunekko 自己的頁面上進行，再轉交給這個分頁。 支援字幕檔與 .zip，不支援 .rar / .7z。

    2.

    Gemini 開啟方式

    捷徑的做法：在「捷徑」App 建一個接收文字的捷徑，加入 Gemini 的「Ask Gemini」動作，內容放「捷徑輸入」。 捷徑模式只把這段日文原文傳過去；網頁版複製「解說日文：」＋這段日文。 要怎麼解說交給你的捷徑與 Gemini 個人化設定。

    分段設定

    打完停一下或離開輸入框就重新分段，設定會記住。停頓 0.5～60 秒、一段 20～5000 字。只對有時間軸的字幕（.srt／.vtt／.sbv）有效。
